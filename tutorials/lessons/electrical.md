# 电路与电平基础

## 先让电流有一条完整的路

本页使用 [Learning07_Blink 完整工程](../projects/Learning07_Blink.alice.json)，源码在 [main.c](../examples/Learning07_Blink/Core/Src/main.c)。先在 AliceSIM 打开工程、构建并运行，观察绿灯每隔约半秒亮灭。只用这一颗灯，先把接线、电平和程序之间的关系弄清。

完整支路是：PB12 → 330 Ω 电阻 → LED 阳极 A → LED 阴极 K → GND。MCU 的 VDD 接 3.3 V，VSS 接同一个 GND。PB12 输出高电平时，GPIO 向这条支路提供电流；低电平时两端电压不足，LED 熄灭。GND 是电压的参考点，也参与回流，不能理解成“多余的线”。

电压像两点之间的差，单位 V；电流是通过支路的电荷流动速率，单位 A 或 mA；电阻限制给定电压下的电流，单位 Ω。知道“输出了 3.3 V”还不足以判断器件是否能直接连接，必须同时检查电流、极性和允许电压。

## LED 为什么必须串联电阻

LED 的阳极、阴极有方向。实物常见长脚为阳极、平边侧为阴极，但剪过脚或不同封装时要查元件标记、数据手册，不能只凭外观。电路图中 A 是阳极，K 是阴极。

假设某颗 LED 在目标电流附近压降约 2.0 V，GPIO 高电平近似 3.3 V，那么：

```text
电阻两端电压 ≈ 3.3 − 2.0 = 1.3 V
电流 ≈ 1.3 / 330 = 0.00394 A ≈ 3.9 mA
电阻功耗 ≈ 1.3 × 0.00394 ≈ 0.0051 W
```

这是选择量级的估算。实际 GPIO 有压降，不同 LED 颜色和型号的正向压降不同，需按手册核对单引脚和整组 GPIO 电流限制。电阻放在 LED 前后都可以，只要处于同一串联支路。多颗并联 LED 应各自有电阻。

不要省略电阻来“让灯更亮”，也不要直接短接电源与地。AliceSIM 可帮助检查电路网络和亮灭关系，不能替代实物的器件额定值与热设计验证。

## 高低电平、输入与输出

本例的 GPIO 是输出：程序主动把 PB12 驱动为高或低。GPIO 输入则读取外部电平；输入悬空时可能受干扰，通常需要上拉或下拉给出默认状态。

上拉是通过电阻连接到电源，下拉是通过电阻连接到地。比如后面的开关实验使用 10 kΩ 上拉到 3.3 V：开关断开时读高，闭合接地时读低。闭合时电阻电流约为 3.3 / 10000 = 0.33 mA。不能用导线直接上拉后又让开关短接到地。

“3.3 V 逻辑”不表示所有低于 3.3 V 的电压都能可靠读成高。高、低电平都有保证范围，中间可能是不确定区，要看芯片手册对应引脚的输入阈值。5 V 模块也不能随意直连 3.3 V MCU；应查该引脚是否容忍 5 V、工作模式、供电状态与模块实际输出电压。

## 推挽与开漏

推挽输出能主动驱动高和低，本例用它直接控制小电流 LED。开漏输出只能主动拉低；要获得高电平，需要上拉电阻，在释放时由上拉把线路带高。I²C 使用开漏与上拉来让多个器件共享线路。

不要让两个推挽输出直接相连、一个写高另一个写低，这会形成驱动冲突。也不要把 GPIO 当成能直接带动电机、继电器线圈或大功率负载的电源。

## 在 CubeMX 核对最小配置

1. 新建 STM32F103C8T6 工程，把 PB12 设为 GPIO_Output，标签 GREEN_LED。
2. GPIO 设置 Output Push Pull、No Pull、Low speed，初始输出 Low。
3. RCC 使用内部 HSI，HSE 设为 Disable，PLL 关闭；时钟树选择 HSI 为 SYSCLK，AHB、APB1、APB2 不分频，均为 8 MHz。
4. SYS → Debug 选择 Serial Wire，保留 PA13/PA14；SysTick 作为 1 ms 时间基准。
5. 生成后核对 GPIO 初始化、时钟初始化与电路引脚。实物工程生成方式见 [把程序放到真实开发板](hardware.md)。

程序里的这行翻转的是 PB12 的电平：

```c
HAL_GPIO_TogglePin(GREEN_LED_GPIO_Port, GREEN_LED_Pin);
HAL_Delay(500U);
```

宏在 main.h 绑定到 GPIOB 和 GPIO_PIN_12。HAL_Delay 的单位是毫秒，等待期间主循环停在这里。灯的可见变化还依赖电阻、极性和回流线路，改标签不会自动修好接线。

## 观察、故障与练习

先检查正常亮灭，再一次只改一处，记下预期与结果。可以在逻辑分析仪看 PB12 电平，区分“引脚没有变化”和“引脚变化但灯没亮”。

1. 在 AliceSIM 将 LED 反接，观察 PB12 仍有高低变化而 LED 不正常点亮，然后恢复极性。
2. 在仿真中断开 LED 阴极到 GND 的导线，解释为什么程序正确也不能形成完整电流路径，再恢复接线。
3. 将 LED 支路改接 PB13但保持代码 PB12，尝试从引脚与导线不一致定位问题；恢复后重新构建。
4. 假设目标电流为 2 mA、LED 压降 2.0 V，计算电阻约为 650 Ω，再从常见阻值选择相近而更保守的一档。实物改变前还需核对器件手册。
5. 继续阅读 [单片机与第一个闪灯程序](mcu-first.md)，理解电平是怎样由程序产生的。
