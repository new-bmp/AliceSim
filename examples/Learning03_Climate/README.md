# 例程 03：温湿度采集与四位数码管

在 AliceSIM 中做一次完整的“传感器 → 程序 → 显示”实验：DHT11 提供温湿度，STM32 读取后让 TM1637 交替显示，USART2 输出带单位的数据。不是预设的数码管动画；显示内容来自当次传感器读取。

## 打开与观察

1. 选择“项目 → 打开工程文件夹”，打开整个 `Learning03_Climate` 文件夹。代码、`.ioc` 和同名 `.alice-sch.json` 电路会一起导入。
2. 构建并运行。上电等待约 1.1 秒，数码管先显示 `25`，一秒后显示 `50`，再循环。
3. **冒号熄灭为温度 °C，冒号点亮为相对湿度 %RH**。数码管显示整数，串口保留一位小数并写明 `TEMP`、`HUM`。
4. 在虚拟串口选择 USART2，默认 115200 / 8N1，观察 `TEMP=25.0 C` 和 `HUM=50.0 %RH`。
5. 选中 DHT11，打开元件属性，把环境温度改为 31、湿度改为 72。等下一次采样，数码管与串口应变为 31、72，PB12 独立控制的红色报警灯亮起。降到 30.0 °C 以下，报警灯熄灭。也可以用包络编辑器给这两个环境量设置时间变化。

## 配置与接线

| 模块 | 引脚与设置 | 学习重点 |
|---|---|---|
| STM32F103C8T6 | HSI 8 MHz，调试口 SWD | 时钟设置与工程一致 |
| DHT11 DATA | PB0，驱动切换输入/输出；外接 4.7 kΩ 上拉到 3.3 V | 单总线读取、返回状态 |
| TM1637 CLK / DIO | PB6 / PB7，开漏输出，各接 4.7 kΩ 上拉 | 两根线传送显示数据 |
| USART2 TX / RX | PA2 / PA3，115200、8N1 | 数据格式与核对 |
| 高温报警灯 | PB12 → 330 Ω → 红 LED → GND | 独立 GPIO 输出，温度 ≥ 30.0 °C 时亮 |
| 电源 | 所有器件共 3.3 V 和 GND | 正确供电与共地 |

完整 STM32 HAL / CMSIS 头文件与源文件已包含；AliceSIM 驱动只带本例需要的 DHT11、TM1637 和计时头。`main.c` 包含实际 GPIO、UART、时钟与 SysTick 初始化；`timing.c` 使用 Cortex-M3 DWT 周期计数器提供实机微秒延时。编译器宏为 `USE_HAL_DRIVER`、`STM32F103xB`，头文件路径为 `Core/Inc`、`Drivers/STM32F1xx_HAL_Driver/Inc`、`Drivers/CMSIS/Include`、`Drivers/CMSIS/Device/ST/STM32F1xx/Include`、`Drivers/AliceSIM/Inc`。

## 代码怎么读

先看 `AliceSIM_DHT11_Init` 绑定 PB0；再看循环里的 `AliceSIM_DHT11_Read` 如何把结果写入 `climate_sample`。`temperature_x10`、`humidity_x10` 表示实际量乘 10，串口格式化时拆开整数与小数。显示 API `AliceSIM_TM1637_DisplayNumber` 的最后一个参数控制冒号，便于区分当前显示量。

每轮只采集一次，两种显示各保持约一秒，所以 DHT11 读取间隔至少两秒，符合驱动不小于一秒的限制。读取失败时清空数码管并输出 `DHT11 ERROR=...`，不把旧值当成新测量。

## 自己改一改

- 改变亮度参数 0～7，比较显示效果。
- 改成每两秒切换一次，检查传感器采样间隔怎样变化。
- 修改 `HIGH_TEMPERATURE_X10` 高温阈值，验证刚低于、刚达到和刚高于阈值的状态。比如 `300` 表示 30.0 °C。
- 增加另一只独立 LED 表示高湿告警，先写出阈值，再改变环境验证边界。
- 增加温湿度最大/最小值统计，通过串口观察计算过程。

数码管整数显示是本例的取舍，不代表传感器没有小数。AliceSIM 使用驱动语义与接线模型验证程序逻辑；单总线边沿精度、DHT11 实际误差、供电与拉电阻请结合数据手册和实机确认。

真实 DHT11 常见规格的温度范围为 0～50 °C；仿真环境面板允许更宽的输入用于软件边界练习，不把这些边界值当作器件实测规格。计时辅助在调用间隔短于一个 DWT 回卷周期时正确累计回卷；本例两秒一次读取满足这一条件。

## 已验证与拍摄建议

`verify.py` 会构建真实工程模型，并通过固件运行时验证 25.0 °C / 50.0 %RH、31.0 °C / 72.0 %RH，以及负温度输入的数码管和串口结果。运行：`python examples/Learning03_Climate/verify.py`。

录制时先显示完整电路和接线，接着放大 DHT11 属性调整 25/50 → 31/72，最后让数码管完成一次温度/湿度切换，并在同一镜头保留 USART2 的标签。不要把两种数值同时叠在数码管上，也不要用后期改读数。
