AliceSIM 1.1 将 AI 学习助手接入代码、电路和运行观测。学生可以提问、预测、动手验证，把实验中的问题整理成讲义。

## AI 实验陪练

- 结合当前源码、IOC 配置、接线、串口与波形记录理解问题，直接圈选引脚、高亮代码、定位观测区域。
- “先考考我”根据工程提出预测题，支持点选答案和自由表达；“我卡住了”“换个说法”“点评我的预测”可接着讨论当前步骤。
- “跟着做”和“挑战练习”提供分步任务、预测记录与三层提示。可运行多组输入，将目标与实测并排比较，区分通过、未达标和证据不足。
- 生成带原理、代码、连接关系和观测证据的讲义，导出 Markdown、HTML 或打印为 PDF。对话、任务和进度随完整工程保存。
- 设置界面支持兼容 Chat Completions 的模型服务、连接测试与本机配置保存；API 密钥留在本机后端，不进入工程包。

## 教程、外设与修复

- 配套 31 篇教程、14 套课程工程，涵盖 C 基础、GPIO、ADC、PWM、UART、I²C、SPI、中断与 DMA；另含 ST7789 彩屏例程和驱动。
- 扩充显示器、传感器、执行器的运行效果，增加 ST7789 SPI 彩屏以及配套驱动，更新应用图标。
- 修复逻辑分析仪的 PWM 边沿显示。
- 修复 CubeMX IOC 导入后的时钟显示同步，正确反映工程配置的 72 MHz 等时钟值。

Windows 用户需安装 64 位 Python 3.10+，完整解压源码包后双击 `AliceSIM.cmd`。首次启动需要联网准备 Clang 和依赖。C++ 工程还需要 GNU Arm 工具链，具体见 [启动说明](https://github.com/new-bmp/AliceSim/blob/v1.1.0/README.md#快速开始)。

AI 助手需在顶部齿轮的“AI 模型设置”中配置自己的服务，详见 [配置与使用说明](https://github.com/new-bmp/AliceSim/blob/v1.1.0/docs/ai-learning-foundation.md)。AI 提供提示与教学任务，修改代码由学生完成；自动验收针对本机 HAL 语义级仿真结果。
