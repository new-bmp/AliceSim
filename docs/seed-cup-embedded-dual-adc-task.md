# 2026“种子杯”嵌入式赛道题目

## 双路模拟量采集与状态指示终端

**题型**：工程实现　**仿真平台**：AliceSIM　**目标器件**：STM32F103C8T6　**满分**：100 分（DMA 扩展最多加 10 分）

## 一、题目背景

在工业控制、环境监测和电池管理设备中，单片机通常需要同时读取多个模拟量，并通过显示屏和串口向操作人员提供结果。本题要求选手在 AliceSIM 中完成一个双路模拟量采集终端：两个模拟源分别接入 STM32F103C8T6 的 PA0 和 PB0，OLED 显示换算后的电压，USART2 输出同一份数据；运行开关和双色状态灯用于表示设备是否处于采集状态。

本题考查 STM32 HAL 外设初始化、ADC 采样与量程换算、I²C 显示、串口格式化、GPIO 输入输出和基本控制逻辑。所有输入均由仿真电路提供，禁止使用固定数值冒充采样结果。

## 二、起始工程与平台

出题方提供下列工程目录作为起始工程：

`examples/STM32F103_HAL_Init/`

工程中已经包含 CubeMX IOC、STM32 HAL/CMSIS 头文件和源文件、AliceSIM SSD1306 驱动，以及配套电路文件：

`examples/STM32F103_HAL_Init/STM32F103_HAL_Init.alice-sch.json`

导入工程后，使用 AliceSIM 的“构建”和“仿真”页面完成验证。仓库中的 `Core/Src/main.c` 是出题方参考实现；正式发放选手包时，可以将应用区替换为待完成的起始代码，但必须保留同一 IOC 配置和电路连接。

## 三、硬件连接

| 功能 | 元件/网络 | STM32 引脚 | 说明 |
|---|---|---|---|
| 模拟量 1 | `ADC_PA0` AO | PA0 / ADC1_IN0 | 0～3.3 V，默认 1.100 V |
| 模拟量 2 | `ADC_PB0` AO | PB0 / ADC2_IN8 | 0～3.3 V，默认 2.200 V |
| 运行开关 | `SW_RUN` | PA1 | 上拉输入；开关导通时为低电平 |
| 状态灯控制 | `STATUS_LED` | PB12 | 一个 GPIO 控制两只反向并联的 LED 支路 |
| OLED 时钟 | `OLED1.SCL` | PB6 / I2C1_SCL | SSD1306，7 位地址 `0x3C` |
| OLED 数据 | `OLED1.SDA` | PB7 / I2C1_SDA | 100 kHz I²C |
| 串口发送 | USART2 TX | PA2 | 115200，8N1 |
| 串口接收 | USART2 RX | PA3 | 保留配置，可不使用 |

双色灯不是两个 GPIO：PB12 输出高电平时绿灯支路导通、红灯熄灭；PB12 输出低电平时红灯支路导通、绿灯熄灭。电路中的两个 330 Ω 电阻用于限流。

## 四、功能要求

### 4.1 初始化

完成 `HAL_Init()`、时钟和 IOC 中已配置外设的初始化。应用代码至少应正确初始化 ADC1、ADC2、I2C1、USART2 和 GPIO。OLED 初始化失败时不得继续报告“采集正常”。

### 4.2 运行开关与状态灯

程序循环读取 PA1：

- PA1 为低电平（`SW_RUN` 导通）时进入采集态：PB12 输出高电平，绿灯亮、红灯灭。
- PA1 为高电平（`SW_RUN` 断开）时进入待机态：PB12 输出低电平，红灯亮、绿灯灭。

待机态必须暂停 ADC 采样和周期性串口发送，不能继续刷新上一轮的采样报告。

### 4.3 双路 ADC 采集与换算

采集态下分别读取 PA0 和 PB0 的 ADC 值，建议周期为 100 ms。STM32F1 的 ADC 分辨率为 12 bit，参考电压为 3.3 V，换算关系为：

`voltage_mV = raw × 3300 / 4095`

显示和串口均保留 1 位小数。允许使用整数定点运算，推荐将结果保存为 `mV × 10`，避免使用浮点格式化造成额外依赖。换算结果必须来自当前电路中的 AO 电压，不能写死为默认值。

### 4.4 OLED 显示

采集态 OLED 只显示以下四行信息，示例格式如下：

```text
DUAL ADC INPUT
PA0 1100.0 mV
PB0 2200.0 mV
UART2 115200
```

其中两路数值随仿真中的 ADC 采集源实时变化。OLED 可显示标题和接口速率，但不得显示 ADC raw 数值、仿真器状态、I²C 地址或其他会遮挡数据的调试信息。

待机态 OLED 显示居中的：

```text
READY
```

### 4.5 USART2 输出

采集态每个采样周期发送一行 ASCII 文本：

```text
PA0=1100.0mV PB0=2200.0mV\r\n
```

串口参数为 115200、8 数据位、无校验、1 停止位。待机态不发送新的采样行。输出字段顺序、单位、小数位和换行符必须保持一致。

### 4.6 稳定性要求

程序应持续运行，不得因一次 ADC 超时、无效输入或显示刷新失败而输出虚假的“正常采集”状态。不得在循环中创建无界增长的缓冲区；串口与 OLED 缓冲区长度应明确且足够覆盖规定格式。

## 五、验收场景

评测人员在不修改 IOC 和电路连接的情况下，至少执行以下场景：

| 场景 | 仿真操作 | 预期结果 |
|---|---|---|
| 上电待机 | 保持 `SW_RUN=OFF` | OLED 显示 `READY`；红灯亮；绿灯灭；串口无周期采样行 |
| 默认采集 | 切换 `SW_RUN=ON` | OLED 显示四行采集界面；绿灯亮；红灯灭；USART2 周期输出 |
| 改变模拟量 | 将 `ADC_PA0`、`ADC_PB0` 调到任意 0～3.3 V 值 | 两路显示和串口均随输入改变，误差不超过 1 个 ADC 量化步进加 5 mV |
| 再次待机 | 切回 `SW_RUN=OFF` | OLED 回到 `READY`；红灯亮；不再发送新的采样行 |

在 3.3 V 参考下，1 个 12 bit ADC 量化步进约为 0.806 mV。显示值按题面要求保留一位小数，判定时以实际采样量化后的结果为准。

|---|---:|---|

| 双路 ADC 采集与换算 | 25 | PA0/PB0 通道正确；按 3.3 V、12 bit 换算；数值跟随输入 |
| OLED 显示 | 20 | 四行格式正确；显示一位小数；不显示 raw 和调试状态；待机显示 READY |
| USART2 输出 | 15 | 115200 8N1；格式、单位、换行正确；采集态周期输出 |
| 代码质量与鲁棒性 | 10 | 变量命名清晰；缓冲区有界；无固定值冒充采样；状态切换无明显闪烁 |
| DMA 扩展（加分） | +10 | 使用已配置的 DMA 语义完成连续采样或串口发送，并能在逻辑分析仪/运行摘要中观察到 DMA 传输；不得改变基本功能 |

## 七、实现约束

1. 目标芯片、IOC 引脚和电路连接必须保持不变；不得通过更换元件或修改 AO 电压来规避采集逻辑。
2. 使用 C 和 STM32 HAL 完成功能，允许在 `Core/Src`、`Core/Inc` 和 `Drivers/AliceSIM` 中添加必要的应用代码或驱动封装。
3. 必须保留 `main()` 入口和正常的 HAL 初始化流程；禁止用死循环、固定延时截图或静态字符串替代外设行为。
4. 可使用 `if/else`、`while`、`for`、`switch`、`return`、`break`、`continue` 等 C 基本控制语句；不要求选手实现完整寄存器级 ADC 驱动。
5. 显示屏和串口的判定以仿真运行时的实际外设事件为准，不能只修改界面文本。

## 八、提交内容

提交一个可导入 AliceSIM 的工程文件夹，至少包含：

- `.ioc` 工程配置；
- `Core/Inc` 与 `Core/Src` 中的应用代码；
- 使用到的 `Drivers/AliceSIM` 驱动文件；
- 配套 `.alice-sch.json` 电路文件；
- `README.md`，说明编译、运行和测试方法；
- 一份简短测试记录，至少包含 OFF、ON、改变两路模拟源后三种结果。

文件夹名称建议为 `SeedCup_DualADC_<队伍名>`。提交前请在 AliceSIM 中重新导入该文件夹，执行一次构建、运行和复位，确认没有依赖本机绝对路径或未提交的文件。

## 九、出题方验收流程

1. 打开工程文件夹，确认 IOC、源码和电路文件自动关联。
2. 执行构建，检查 Clang 诊断、HAL 模型和外设连接均通过。
3. 进入仿真页，先观察 OFF 状态，再切换 `SW_RUN` 至 ON。
4. 在电路页修改两个 ADC 采集源，核对 OLED 与串口的带小数毫伏值。
5. 打开逻辑分析仪或串口面板检查周期、格式和状态切换；需要评估 DMA 加分时，检查运行摘要中的 DMA 传输记录。
6. 切回 OFF 并复位，确认 `READY`、红灯和无周期发送三项同时成立。

本题的参考电路已经按“MCU—显示—模拟输入—状态指示—开关”分区重新排布，元件标签和导线均可在电路页中按需隐藏或调整，不影响网络连接和评分规则。
