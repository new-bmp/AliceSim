# 元件的实时显示

电路图中的输出元件使用设备状态绘图。显示不会自行播放循环动画：程序暂停后保留最后的输出；电源断开后数码管、点阵和灯带熄灭。元件的连接状态放在图形下方，可以随“标签”开关隐藏。像素、灯珠和刻度不属于名称标签。

| 元件 | 画面上的变化 | 数据来自哪里 |
| --- | --- | --- |
| SG90 | 摇臂方向、角度 | 已接线且供电正常的 PWM，或已有 AliceSIM 舵机驱动操作；500–2500 μs 对应 0–180°。PWM 停止时保持最后位置 |
| TM1637 | 四位独立段码、小数点、冒号、亮度 | 已有 TM1637 设备状态及 AliceSIM 驱动操作；亮度 0 是最低亮度，关闭显示使用使能位 |
| MAX7219 | 8×8 LED 点阵、扫描行数、亮度、显示测试 | HAL SPI 发送的寄存器地址和数据，CS 上升沿锁存；跨多次传输保存移位状态 |
| WS2812 | 每颗灯珠独立 RGB 颜色 | SPI MOSI 上的三位编码：`100` 为 0、`110` 为 1，GRB 高位先发；至少 50 μs 的低电平复位后更新 |
| 无源蜂鸣器 | 发声时出现声波标记，停止后消失 | 已有蜂鸣器驱动状态或 PWM。这里只显示状态，不播放声音 |
| 继电器 | 指示灯、COM→NO / COM→NC 触点位置 | IN 的实际电平及线圈供电；触点会连接相应电路网络，悬空输入不会误触发 |
| 电位器、编码器、摇杆 | 旋钮方向、杆位置、按压标记 | 属性面板或包络中的输入值；原有 ADC / GPIO 采样路径继续使用这些值 |
| HC-SR04 | 目标位置和距离数值 | 配置的目标距离，与测距模型使用同一个值 |
| DHT11、SHT30、DS18B20 | 温度柱、湿度刻度 | 配置的环境参数 |
| BH1750、BMP280、MQ-2、INA219 | 光照强弱、气压 / 浓度 / 电流指针；气体越阈值变色 | 配置的物理量；MQ-2 的原有 AO / DO 路径保留 |
| MPU6050、PIR | X 轴加速度示意、角速度向量、运动标记 | 配置的输入参数。MPU 图形不是完整的姿态解算 |
| PCF8574、PCA9685 | 八位电平、通道 0 PWM 占空比示意 | 配置的输入掩码和 PWM 参数 |
| DS3231 | 指针和 UTC 时间 | 配置的 Unix 时间；尚不随仿真时间自动走时 |
| MOSFET、DC-DC | 导通通道、负载条、超载提示 | 原有电路计算结果 |

## SPI 输出的接线和限制

MAX7219 的 DIN、CLK 接 IOC 所指定 SPI 的 MOSI、SCK；CS 接 GPIO。每次拉低 CS，发送寄存器地址和数据，再拉高 CS。支持 1–8 行数据、Code-B、亮度、扫描限制、关断和显示测试寄存器。当前是单模块模型，未实现多片级联。这里接入的是 HAL SPI 字节传输，并未扩展所有 `AliceSIM_MAX7219_*` 高层编译入口。

WS2812 的 DIN 接 SPI MOSI，供电和地分别连接。SPI 使用 8 位、MSB first，位率在 2.2–2.7 MHz 内，典型为 2.4 MHz。位率根据 IOC 的 APB 时钟和 SPI 分频确定；没有时钟信息或编码不匹配时不会猜测颜色。复位低电平需包含在发送数据末尾，例如在 2.4 MHz 下附加至少 15 个全零字节。支持一个传输拆成多个 HAL SPI 调用；每串最多 256 颗。PWM-DMA 和 GPIO 位操作驱动的 WS2812 解码尚未实现。

有图形不等于该器件的全部总线协议已实现。仍属通用参数模型的器件会标注“参数预览”；本次没有新增这些器件的 I²C 寄存器协议或 W25Qxx 存储读写模型。OLED、ST7735 继续使用原有的像素帧缓冲。
