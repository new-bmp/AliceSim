# 元件的实时显示

电路图中的输出元件使用设备状态绘图。显示不会自行播放循环动画：程序暂停后保留最后的输出；电源断开后数码管、点阵和灯带熄灭。元件的连接状态放在图形下方，可以随“标签”开关隐藏。像素、灯珠和刻度不属于名称标签。

| 元件 | 画面上的变化 | 数据来自哪里 |
| --- | --- | --- |
| SG90 | 摇臂方向、角度 | 已接线且供电正常的 PWM，或已有 AliceSIM 舵机驱动操作；500–2500 μs 对应 0–180°。PWM 停止时保持最后位置 |
| TM1637 | 四位独立段码、小数点、冒号、亮度 | 已有 TM1637 设备状态及 AliceSIM 驱动操作；亮度 0 是最低亮度，关闭显示使用使能位 |
| MAX7219 | 8×8 LED 点阵、扫描行数、亮度、显示测试 | HAL SPI 发送的寄存器地址和数据，CS 上升沿锁存；跨多次传输保存移位状态 |
| WS2812 | 每颗灯珠独立 RGB 颜色 | SPI 三位编码或定时器 PWM/DMA 脉冲，解码 GRB 数据并检查复位低电平 |

## SPI 输出的接线和限制

MAX7219 的 DIN、CLK 接 IOC 所指定 SPI 的 MOSI、SCK；CS 接 GPIO。每次拉低 CS，发送寄存器地址和数据，再拉高 CS。支持 1–8 行数据、Code-B、亮度、扫描限制、关断和显示测试寄存器。当前是单模块模型，未实现多片级联。这里接入的是 HAL SPI 字节传输，并未扩展所有 `AliceSIM_MAX7219_*` 高层编译入口。

WS2812 的 DIN 可以接 SPI MOSI，也可以接 IOC 指定的定时器 PWM 引脚。SPI 使用 8 位、MSB first，位率在 2.2–2.7 MHz 内，典型为 2.4 MHz；`100` 编码 0，`110` 编码 1。复位低电平需包含在发送数据末尾，例如在 2.4 MHz 下附加至少 15 个全零字节。支持拆成多个 HAL SPI 调用，每串最多 256 颗。

PWM 路径使用约 800 kHz 的周期，把 `uint16_t` 比较值缓冲区解码为高电平脉宽，末尾保留至少 50 μs 低电平。支持 `HAL_TIM_PWM_Start_DMA` 完整帧及 AliceSIM 驱动中直接转发该调用的发送回调。目前整帧同步交付，未模拟定时器 DMA 半满/完成回调和循环 DMA。任意 GPIO 位操作时序暂不解码。缺少具体引脚、时钟或正确脉宽时不会显示猜测的颜色。

OLED 支持对比度和按仿真时间滚动；ST7735 支持 MADCTL 方向、RGB/BGR、反色及 RGB565/RGB666 数据。TM1637 支持原始段码、局部写入、独立冒号与亮度。

BMP280、MPU6050、BH1750、SHT30、INA219、DS3231、PCF8574、PCA9685 已接入 I²C 读写，W25Qxx 已接入 SPI 读写。电源、地址和 IOC 总线引脚必须匹配；I²C 同址器件会报告冲突。可在属性面板修改七位地址。协议范围及 Flash 保存限制见 [外设总线模型](peripheral-bus-models.md)。

DS18B20 支持随附驱动的初始化、启动转换、读取原始温度及摄氏度换算。编译器从总线回调中的 HAL GPIO 调用确定 DQ 引脚；电路上的 DQ 必须接到同一引脚。12 位转换需等待 750 ms，提前读取得到上次结果（上电初值为 85°C），支持负温度。断电、错接 DQ 或同一 DQ 上多个 Skip ROM 器件会返回失败。此路径使用驱动语义，尚不解码任意 GPIO 波形或 ROM 搜索。回调与指针的具体范围见 [DS18B20 温度模型](ds18b20-model.md)。
